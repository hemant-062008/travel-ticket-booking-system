# Project Summary
## Bus / Train Ticket Booking System

### 1. Introduction
The Bus / Train Ticket Booking System is a simple Python project. It helps users book tickets, check available seats, view bookings, and cancel tickets.

### 2. Objective
The main objective of this project is to make ticket booking simple and easy using Python.

### 3. Features
- View available seats.
- Book a ticket.
- Enter passenger name.
- View all booked tickets.
- Cancel a booked ticket.
- Calculate an 80% refund after cancellation.
- Show a message when all seats are booked.

### 4. Technologies Used
- **Programming Language:** Python
- **Editor:** VS Code

### 5. Python Concepts Used
- Variables
- Lists
- Dictionaries
- Functions
- If-Else Conditions
- For Loop
- While Loop
- Try-Except

### 6. Project Details
- Total Seats: 10
- Ticket Price: ₹500
- Refund: 80% (₹400)
- Booking Type: Console-based

### 7. How to Run the Project
1. Open the project folder in VS Code.
2. Open the `bus_booking.py` file.
3. Run the Python program.
4. Select an option from the menu.
5. Follow the instructions on the screen.

### 8. Conclusion
This project helped me understand the basic concepts of Python programming. It also helped me learn how to use lists, dictionaries, functions, loops, and conditions in a simple real-life project.
